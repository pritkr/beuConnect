## 🎯 The Mission
**Objective:** Obliterate and replace competing platforms like `apnabeu` (Android App) and `beubih.vercel.app`. 
This project aims to be the ultimate, fastest, MVP-ready, and user-friendly web app for all Bihar Engineering University (BEU) students. It acts as a centralized hub for studies, syllabus, PYQs, connection, and result tracking.

## 🛠 Tech Stack
- **Web Framework:** Astro (SSR deployed via Cloudflare Workers `@astrojs/cloudflare`)
- **Styling:** Pico.css (`@picocss/pico`)
- **Package Management:** `bun` (for Node JS/Astro), `uv` (for Python scripts)
- **Data Storage:** Zero-cost, highly portable architecture using CSV files generated by Python scrapers. No traditional database is used to keep costs at zero and allow for easy data analysis.

## 📂 Architecture & Directory Structure
- **`src/`**: The core Astro application.
  - **`src/pages/api/result.ts`**: The core API handler for fetching, scraping, and normalizing student results directly from official BEU/AKU result websites based on registration number and semester.
- **`native/`**: The NativeShell app (Android-first, real native views). Own routes, design system, offline data and QA. Read `native/AGENTS.md` first; deep docs in `native/docs/`.
- **`sylpy/`**: Python scripts used for extracting data from BEU Syllabus PDFs and converting them to simple text.
- **`gatextract/`**: Python scripts dedicated to extracting GATE syllabus from PDFs.
- **`pythonscripts/`**: Python scraping and automation scripts that pull student result data and export them as CSV files. These scripts are run locally. The generated CSVs feed the "Result Tables", allowing for ranking and merit lists per college.
- **`25listextractfrompdf/`**: Specific Python extraction scripts initially built to extract data for the 2025 batch students of GEC Sheikhpura.

## 🚀 Key Features & Roadmap
1. **Result Scraping & Redesign:** Auto-fetch results via `api/result.ts` and display them in a clean, modern UI (bypassing the official university site's poor UI).
2. **Result Tables:** College-wide and branch-wide result aggregations sorted by CGPA/SGPA using pre-scraped CSV data.
3. **Resource Hub:** Text-extracted BEU & GATE syllabi, with plans to add PYQs, pirated course links, NDL integration, and internships.
4. **Competitive Features (To Obliterate Apna BEU):**
   - **SGPA Calculator/Predictor:** Allow students to predict their SGPA based on internal and external marks.
   - **Result Battle (1v1):** A fun feature to compare results side-by-side with friends.
   - **University/Branch Rank:** Clear rank indicators based on the scraped CSV data.
   - **Exams Info Hub:** Pages for GATE, DRDO, ISRO, UPSC, etc.
   - **Attendance Tracking & Routine:** Simple utilities for day-to-day student life.
   - **Notice Board:** Aggregated notices from BEU.
5. **Target Milestones:** Prioritize shipping core features fast to capture the user base before competitors can improve their UX.
