# Data pipelines in full

All commands run from the repo root unless a step says `native/`.

## 1. Bundled syllabus, GATE, holidays, grading, colleges

```sh
uv run python native/scripts/extract.py
uv run python native/scripts/verify.py
```

- `extract.py` reads the site's JSON/pages and rewrites `native/assets/data/`
  plus `manifest.json`. Standard library only; safe to rerun.
- `SOURCE_DATE_EPOCH=$(git log -1 --format=%ct)` makes `generatedAt`
  reproducible.
- `verify.py` checks manifest counts, per-file counts, unique IDs, branch
  summaries, dates, grade thresholds and documented gaps. Non-zero on failure.
- Expected totals (as of the last verified run): 343 subjects, 1,405 units,
  2,324 topics, 19 stubs, 30 GATE papers, 232 sections, 504 topics, 39 holidays,
  7 grades, 52 colleges. If these move, the manifest and `verify.py` must agree.

## 2. Student register

Two separate outputs, two scripts:

```sh
# native/assets/data/students-gecs.json + src/data/students/*.csv + manifest
uv run python native/scripts/build-students-data.py
uv run python native/scripts/build-students-data.py --check

# src/features/students/roster-data.ts (the packed app wire form)
bun scripts/build-students-data.mjs
bun scripts/build-students-data.mjs --check
```

- Source: `src/data/students/gecs-{cse,ece,ee,mech,civil,met}.csv` plus
  `gecs-archive-2019-2021.csv`. The `.mjs` builder names its inputs instead of
  globbing (the older `gecsheikhpura*.csv` files would double-pack every row).
- The register's `Session`/`Batch` is authoritative; a year-back student can
  have an earlier registration year.
- `--check` must pass before committing. It compares every record and count.

## 3. Syllabus packs

```sh
cd native
bun scripts/data/build-packs.ts              # lossless re-pack
bun scripts/data/build-packs.ts --check      # stale check
bun scripts/data/build-packs.ts --from-site  # import newer site JSON (needs --write)
bun scripts/data/verify-packs.ts             # decode + counts + per-branch hash
```

`packs.ts` is generated; `data/table/` holds the deduplicated prose. The wire
format is documented in `src/features/syllabus/data/decode.ts`. A plain run is
byte-identical when nothing changed.

## 4. PYQ catalog

```sh
# readable catalog: generated by the site-side scraper
uv run python native/src/features/pyqs/scripts/generate_catalog.py
# shipped wire form
bun scripts/pack-pyq-catalog.mjs
bun scripts/pack-pyq-catalog.mjs --check
```

The packer refuses to write unless the decoded output matches the input
exactly. `catalog-data.ts` is the one generated file in `src/features`.

## 5. PYQ PDFs

```sh
bun scripts/build-pyq-pdfs.mjs
bun scripts/build-pyq-pdfs.mjs --check
```

Inputs: `beu_dataset/pdfs/*.pdf` and `beu_dataset/beu_btech_question_papers.csv`.
Outputs: `public/PYQPDFs/`, `public/data/pyq-pdfs.json`,
`native/src/features/pyqs/pdf-catalog.ts`. Mirroring removes papers no longer in
the dataset; identical input writes nothing.

## 6. Notes & VVI

```sh
uv run native/scripts/notes/build-notes.py
uv run native/scripts/notes/build-notes.py --check
```

Inputs: `native/notes-src/vvi/<branch>-<sem>.json` and
`public/notes/<branch>/<sem>/<code>/*.pdf`. Output: `public/data/notes.json`
(generated, fetched by the app). Adding a PDF without rebuilding the manifest
means the app cannot see it.

## 7. Generated navigation snapshot

```sh
cd native
bun qa/scan-push-targets.mjs          # rewrite qa/push-targets.ts
bun qa/scan-push-targets.mjs --check  # stale check (run by qa/run-tests.sh)
```

Not data, but the same rule: it is generated, and a stale snapshot lets a
`nav.push("typo")` ship green.
