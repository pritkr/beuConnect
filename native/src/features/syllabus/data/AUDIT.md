# Syllabus data audit

Snapshot **2026-10-28** · generated by `native/scripts/data/build-packs.ts` ·
sources `src/assets/data/branches/*.json` and `src/assets/data/gate/*.json`.

`packs.ts` is generated; `decode.ts` expands the wires back to the shape the
screens read. This file records what is in the shipped packs, where each row
came from, and every gap that is still open. Nothing here is invented: a
semester or paper the upstream data does not have is listed as missing, not
filled in.

Verified against the packed exports, not against the generator:

```sh
cd native && bun -e '
const m = await import("./src/features/syllabus/data/packs.ts");
let s = 0, c = 0;
for (const raw of Object.values(m.BRANCH_PACKS))
  for (const subs of Object.values(JSON.parse(raw).semesters)) {
    s += subs.length; c += subs.filter((x) => x.content).length;
    for (const x of subs) if (!x.name || !x.code || x.credits == null) throw x.name;
  }
console.log({ branches: Object.keys(m.BRANCH_PACKS).length, subjects: s, withContent: c,
  gate: Object.keys(m.GATE_PACKS).length });
'
```

Result: **6 branches · 33 semester blocks · 360 subjects · 347 with unit text ·
30 GATE papers · 299 sections · 4,832 topic lines · 599,480 chars.** Every pack
parses, no semester block is empty, no duplicate `(branch, semester, code)`, and
every subject has `name`, `code`, `credits` and `content` (empty string only in
the 13 stubs below).

### Sem 4 is the 2024-28 scheme, not the 2022-26 one

BEU runs two Sem-IV curricula at once, and they share code numbers while naming
different subjects:

| Code | 2022-26 scheme | 2024-28 scheme (current batch) |
|---|---|---|
| `103402` | Electrical Machines-II | Signals and Systems |
| `101401` | Civil Engineering – Societal & Global Impact | Transportation Engineering |
| `102401` | Thermodynamics | Applied Thermodynamics |
| `104401` | Analog Circuits | Analog Electronics and Integrated Circuits |

So a scanned paper's printed code only dates the scheme it was set under; the
2022–2025 papers in `src/content/pyqs/` cannot identify a 2024-28 row. The
authoritative list for the current batch is BEU's *Programme for B.Tech/B.Arch
4th Semester Examination 2026* (Batch 2024-28), and it agrees code for code with
the official *B.Tech (…), (SESSION 2024 onwards), Semester-IV* documents. All six
branches' Sem 4 rows are now transcribed from those documents — EE and CSE were
already correct, CIVIL/ECE/MECH were not, and EEE had no Sem 4 rows at all.

The old rows were not merely misnamed: they duplicated 3rd-semester subjects
(CIVIL 3 already carried `101305` Fluid Mechanics, MECH 3 Thermodynamics and
Material Science), so a 2024-28 student saw the same paper twice and never saw
Transportation Engineering, Applied Thermodynamics or Digital Circuits.

Where a document disagrees with itself, the semester table wins, because only it
reconciles with the printed TOTAL:

- CIVIL `101404` prints 2-0-0-2 and `101405` 3-1-0-4 on their own pages but
  3-0-0-3 each in the table; 26 credits only adds up with the table.
- CIVIL's lab page prints `Course Code- 101401` for the Transportation lab; the
  table's `101401P` is the code the app ships.
- MECH prints `Unit- 3.0` twice in `102403`, ECE prints `Unit- 4.0:` with no
  title in `104403`, and CIVIL repeats 101401's hour counts in `101405`. All three
  are BEU's own typos, kept verbatim rather than silently corrected.

with no word changed). `110405` Engineering Mechanics is byte-identical to the
EE and MECH Sem 3 copy of the same paper, BEU's `oplanar` typo included, which
cross-validates the transcription.

## 3. Gaps, and why they are still gaps

**15 missing semester blocks.** CSE 7–8, ECE 6–8, EE 6–8, MECH 7–8, CIVIL 7–8,
EEE 5 and 7–8. The site JSON has no rows for them, and BEU has not published
those schemes in a form this repo holds, so the app shows no tab rather than a
blank semester.

**13 subjects with no unit text.** Elective/skill baskets BEU never published a
unit list for, plus lab rows the site stores without prose; the screen shows
"No unit text for this paper" and the row keeps its code (minted `X-…` where
upstream is blank), credits and type.

**Truncated titles.** Several upstream names stop mid-word — MECH 5
`Constitution of India / Essence of Indian`, EE 5 `Professional Elective
Laboratory -`, `Graduate Employability Skills and`. They are rendered exactly as
the source stores them. Completing them is a generator/upstream change
(`scripts/data/build-packs.ts` or the site JSON), outside this data folder.

**GATE.** No gaps: every one of the 30 papers has ≥3 sections and ≥32 topic
lines. The 8 PDF-sourced papers were transcribed from the official 2026
syllabus, not from memory.

## 4. Size budget

`build-packs.ts --check` reports 795,007 chars of prose in 734 strings,
534,426 chars packed (67.2%), 32,929 chars of wires and 767,361 B across 24
modules (21 chunks, largest 45,479 B). `packs.ts` itself is 34,473 B and the
whole `data/` folder is ~800 KB of source — comfortably under the 1.2 MB APK
warning line.

`verify-packs.ts` passes: 36 canonical JSON documents, 360 subjects, 1,850
references, 299 GATE sections. Its snapshot is the invariant the app ships, so
regenerate it with `--capture` only when the data changes on purpose.
