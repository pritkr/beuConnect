# `syllabus` — BEU syllabus and GATE, offline

Every paper the app knows about: 6 branches, the semesters each one publishes,
1,407 units split into 5,488 tickable topics, a search across all of them, the
papers a student saved, and 30 GATE papers. The data ships in the bundle, so the
whole area opens with the network down.

Generated data is described in [`AGENTS.md`](./AGENTS.md); the site-to-app
comparison and every known gap live in
[`docs/SYLLABUS_PARITY.md`](../../../docs/SYLLABUS_PARITY.md).

## Routes

| Name | Params | Screen |
|---|---|---|
| `syllabus` | `branch?`, `sem?` (deep link; otherwise the profile's course, then the saved course) | Branch rail, semester rail, progress, the semester's papers |
| `syllabus.subject` | `code` (required), `branch?`, `sem?`, `unit?`, `topic?` (jump targets) | Units → topics, full source text, save, ticks, notes, papers |
| `syllabus.search` | `q?` (seed) | Cross-paper search: code, paper name, unit and topic body |
| `syllabus.saved` | — | Saved papers and topics, with undo for a removal |
| `syllabus.gate` | `paper?` (e.g. `CS`), `topic?` (saved-topic focus) | GATE paper picker, search, sections → topics |

All five are registered through `syllabusRoutes` in `index.tsx`; the registry
spreads it. An unknown code, branch or semester renders a pick-one state, never
a crash.

## State

Student state only — clearing bundled data must not clear any of it.

| Key | Holds |
|---|---|
| `beu.syllabus.course` | the chosen branch and semester, plus when it was chosen |
| `beu.syllabus.studied` | ticked topics, `branch\|sem\|code\|topicId` → `true` |
| `beu.syllabus.saved` | saved papers and topics, same key shape |
| `beu.syllabus.last` | the paper behind the “continue” card |
| `beu.syllabus.recent` | the last 8 papers opened, newest first |

Storage is async: `parts.tsx` hydrates once into signals and writes on change
(`docs/ARCHITECTURE.md` §8).

## Search

`searchHits(term, branches)` indexes the decoded packs, not the screen: exact
code, code prefix, code substring, paper name, then topic title and body, in
that order. Two characters is the minimum; the title bar counts every match,
while the list renders the first 80. `matchRange` gives the span to highlight,
`matchesIn` the in-paper jump list.

## Data

`data/packs.ts` + `data/table/` are generated by
`scripts/data/build-packs.ts`; `data/decode.ts` documents the wire format.
Never hand-edit a pack — regenerate it (see `AGENTS.md`), then run
`bun scripts/data/verify-packs.ts`.

## Gaps, on purpose

- 19 papers have no source text: they keep their code and credits, open on an
  explained empty state, and offer the full text or the search instead
  (`SYLLABUS_PARITY.md` §4).
- EEE publishes Sem 1, 2, 3 and 6 only; every other semester says so in the rail
  (§5).
- GATE DA, GG, MA, BM, PE, ST, XH and GE ship no site text; the app carries the
  official 2026 wording (§8). Nothing else is invented.
