# `assets/data` — bundled, generated, never hand-edited

Everything here ships inside the APK and is read offline. The files are outputs
of `scripts/extract.py` (and `build-students-data.py` for the register). A hand
edit is erased by the next regeneration and may not be reachable offline at all.

## Files

| File | Contents | Generated by |
|---|---|---|
| `subjects-<branch>.json` | 6 branches, subjects/units/topics | `uv run python native/scripts/extract.py` |
| `gate.json` | 30 GATE papers, sections/topics | same |
| `holidays.json` | 2026 calendar | same |
| `grading.json` | BEU grade bands and pass rules | same |
| `colleges.json` | college/branch coverage | same |
| `branches.json` | branch names and semester coverage | same |
| `students-gecs.json` | GEC Sheikhpura register | `uv run python native/scripts/build-students-data.py` |
| `manifest.json` | counts, paths, stamps, gaps | both (run the register builder after extract) |

## Rules

- **Regenerate, never edit.** `extract.py` is standard-library only and safe to
  rerun; `verify.py` must pass before the change is committed.
- **The manifest stamp changes only with real data.** Use
  `SOURCE_DATE_EPOCH=$(git log -1 --format=%ct)` for a reproducible run.
- **Gaps stay gaps.** A subject with no source text is a stub; a GATE paper with
  no sections says so. No invented prose, date, mark or student.
- **PII is not documentation.** `students-gecs.json` is personal data; do not
  paste rows into issues, tests or screenshots.
- **Size matters.** This directory is most of the bundled payload;
  `./scripts/size-report.sh` after any growth.

## After a change

```sh
uv run python native/scripts/verify.py
./scripts/check.sh test
./scripts/size-report.sh
```
